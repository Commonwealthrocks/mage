VERSION 0.6a - 04/10/2026 [ STARTED ON; 09/09/2026 ]

- Added custom entropy editor dialog with tab cycling, full path preview, and an "apply

- Added context menu options in queue trees to view, edit, or wipe custom credentials.

- Added CLI support for archive verification (--verify <path>).
- Added verification diagnostic log export (.log / .txt).
- Added new verification mode icon (verify.svg) to replace placeholder ok.svg.
- Added extraction behavior settings: "Create archive folder", "Extract here (flat)",

- Added conflict rules for extraction ("Ask", "Skip", "Overwrite") along with batch options.
- Added auto-open output directory toggle for decryption.
- Added dedicated Extraction tab in settings dialog.
- Hardened path resolution against TOCTOU symlink traversal attacks and NTFS junctions.
- Enforced KDF sanity limits to prevent denial-of-service via malicious Argon2id parameters.
- Re-worked tooltip rendering into styled HTML cards with max-width wrapping and dark theme.
- Fixed ugly ass tab scroll arrow buttons and added smooth mouse wheel cycling for all tab bars.

- Locked window sizes with fixed size on all new dialogs to keep layouts intact.
